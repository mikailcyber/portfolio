## Bijwerken

Bewerk de HTML, CSS, script.js of bestanden in assets/ in deze checkout. Commit de wijziging en push naar main. GitHub Actions controleert alle lokale bestandsverwijzingen, verzamelt alleen de websitebestanden in dist/ en publiceert die via GitHub Pages.

```powershell
git add .
git commit -m "Werk portfolio bij"
git push
```

De map .wrangler, privéonderzoeksdocumenten en accountgegevens worden niet gepubliceerd. De oorspronkelijke video-assets zijn behouden. De ZorgKompas-code staat in de afzonderlijke repository https://github.com/mikailcyber/zorgkompas-dp6.
